Free Headshot Crop & Resize: 1080 × 1350 JPG

Updated October 8, 2026 · JobFace product guide

Direct answer: This is a crop-and-resize tool for an existing headshot, not an AI headshot generator. It produces a portrait-shaped 1080 × 1350 JPG from your own image.

Prepare my portrait →

Choose the right input

Start with a recent photo you have permission to edit. Face the camera, use soft light and leave space around your head and shoulders. An uncluttered background must already be present in the source; this tool cannot replace it.

How to use it

  1. Select a JPG, PNG or WebP file up to 20 MB.
  2. Keep “Portrait · 1080 × 1350 JPG” selected and create the preview.
  3. Check the centered crop and download the result. If your destination requires a square, switch to the 720 × 720 option.

Output and example

The output has a 4:5 width-to-height ratio. For a 1600 × 1600 square source, the crop keeps a centered 1280 × 1600 region, removing 160 pixels from either side, then resizes it to 1080 × 1350. You can see the result before downloading.

What this tool does not do

  • It does not create a studio portrait, change clothes or alter facial features.
  • It cannot fix an out-of-focus or heavily compressed source.
  • It does not certify a photo for passports, visas or official identity documents.
  • It does not guarantee that a recruiting platform accepts this size or file weight.

The final file size depends on the picture. Check the destination’s current upload instructions. Very large decoded images over 60 megapixels are rejected to limit browser memory use.

Profile picture versus resume attachment

A public profile can ask for a portrait even when a resume should not contain one. Treat these as separate decisions. Read headshot versus resume photo before inserting a picture into an application document.

Your photo stays in the browser during processing. No sign-up or payment is required; read how privacy works.
