# JobFace 网站维护说明

## 本阶段的实际功能

- 照片：浏览器本地居中裁剪，导出 720×720 或 1080×1350 的 JPG。
- 简历：一种纯文字单栏布局，下载 HTML，再使用浏览器打印为 PDF。
- 不提供背景替换、头像生成、账号保存、付费服务或 ATS 评分。
- 四种展示布局仅为示例，不是四种可下载模板。

## 部署约束

正式域名：https://jobface.wezzik.com/

保留 `vercel.json` 中的 `outputDirectory: "."`。不能恢复把所有路径重写到首页的规则，否则错误网址会返回 200，形成软 404。`404.html` 是错误页面，不纳入站点地图。

先部署预览，再验证 13 个有效页面和随机错误页面；预览验收通过后才发布正式域名。`Ready` 只说明部署完成，不代表页面和下载功能验收通过。

`.vercelignore` 排除了本地报告、测试、环境文件和原始大图片。`.env*`、`.vercel/` 等不得提交仓库。网页只引用 `assets/` 中压缩后的展示图片。

## 本地验收

安装或使用已有的 Playwright、Chromium 和 sharp 测试依赖后，分别运行：

```sh
node tests/server.cjs
node tests/acceptance.cjs
```

测试使用隔离浏览器，不读取日常浏览器账号。`JOBFACE_TEST_URL` 可以切换验收地址。测试覆盖禁用脚本的英文正文、13 个页面、内部链接、结构化数据与可见 FAQ 一致、3 种错误路径、手机照片下载尺寸、简历下载内容及输入转义、坏图片提示、语言切换和统计参数过滤。

预览测试可用 `JOBFACE_PREVIEW_AUTH=1` 读取已有的 Vercel 自动验收凭据，仅发送到本项目的指定预览主机，不关闭部署保护。网络需要时，可通过 `JOBFACE_TEST_PROXY` 指定已运行的本地代理；这不会修改系统网络设置。凭据不落地到测试结果。

## GA4 接入与隐私验收

当前 `assets/analytics-config.js` 的测量编号为空，统计默认不加载。不能将本地事件测试称为 GA4 接入成功。

1. 先授权 Google Analytics 读取权限，列出可访问的数据流。
2. 核实数据流网站地址确实为 JobFace 正式域名；优先复用已有数据流。
3. 将实际测量编号填入配置，不能使用演示编号或其他站点编号。
4. 核对数据流的增强型衡量设置，关闭不需要的表单交互和重复下载自动采集，避免与手动事件重复。
5. 预览验收、正式发布后，使用用户同意统计的真实浏览器访问首页，完成照片下载及简历下载。
6. 在对应 GA4 实时报告中确认 `page_view`、`tool_start`、`photo_download`、`resume_download` 被接收。只看到网页中的代码或本地事件，不算接入完成。
7. 再拒绝统计，确认未来事件停止发送。照片和简历功能不应受影响。

事件只允许固定的工具类型和照片尺寸类别，不发送姓名、联系方式、照片、原始文件名或简历正文。所有页面和事件的地址参数移除查询字符串、哈希片段；来源只保留来源网站。统计同意仅保存在本机，用户可通过页脚修改。

下载事件表示用户点击有效下载，不等于完成招聘网站提交。可识别的 AI 来源访问，不等于全部 AI 引用或曝光。

## 搜索效果复盘

- 正式发布并验收后，从发布次日的完整日期建立基线。当前不能把预览创建日期当作正式发布日期。GSC 可能延迟更新，不能把缺失数据补成零。
- 新站点地图含 13 个规范网址，即原有 11 个网址加关于、隐私页面。
- 每周读取收录、曝光、点击、查询词、落地页；尽量使用已完整更新的 7 天，与此前完整 7 天比较。
- 首个周期从真实发布次日开始累计七个完整日期。此前如数据不足，只报覆盖范围，不计算误导性的增长率。
- 足够曝光后才调整高曝光低点击页面的标题摘要，同时观察可用的下载率。
- 无授权、无数据和真实零值要分别记录；上线、站点地图读取、页面收录和点击增长是不同状态。

## 内容维护
