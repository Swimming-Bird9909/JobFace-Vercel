How to Save a Resume as a PDF From HTML

Published November 18, 2026 · JobFace

How do you turn an HTML resume into a PDF? Open the downloaded HTML file in a browser, open the Print dialog and choose its PDF-saving option. Review the preview, save the file, then reopen the PDF and check the text and page breaks.

Save the PDF in four steps

  1. Download your resume in HTML from the free JobFace resume builder and open the file in your browser.
  2. Use the browser’s Print command. On many desktop browsers, the shortcuts are Ctrl+P on Windows and Command+P on macOS.
  3. Choose Save as PDF or the PDF option offered by your system. Follow the application’s paper-size instructions when supplied, then check the preview.
  4. Save the document under a clear name such as Alex-Morgan-Resume.pdf, and open it to check the saved result.

Fix common export problems

Browser print preview troubleshooting
If you seeTry this
A file path, date or browser page titleTurn off browser headers and footers in print settings if available.
A heading stranded at the bottom of a pageShorten lower-priority content or revise the section order, then export again.
Text that is too smallRestore a readable scale and review page size and margins.
Text that cannot be selected or copiedReopen the original HTML file and print from the browser. A screenshot of a resume loses selectable text.

Check the finished document

Copy a line from the PDF into a plain-text editor and compare it with your source. Check contact details, section order, page count and any file size restriction. Follow the employer’s instructions if they require DOCX or a different format.

See Chrome’s print instructions for the browser options, or use the resume layout checklist for help with spacing.

Does JobFace export a PDF directly?

JobFace downloads a single-column HTML resume. Your browser creates the PDF using its print-to-PDF option. The HTML file remains available for re-exporting a corrected copy.
