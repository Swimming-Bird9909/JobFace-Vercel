Choosing a layout for an application

Prioritize readability and the employer’s instructions over decorative styling. No layout can guarantee acceptance by every applicant tracking system. Use the layout checklist to review section order, spacing and the final file.

Which resume template can I download?

The basic single-column HTML resume is the only downloadable layout. The graduate, technical, business and creative designs are visual examples, not separate download options. Use the basic resume builder to fill the real template with your own text. For content rather than styling, start with resume summary examples and the resume keyword matching checklist.

A simple resume template is a starting point for organizing content. Use the first resume example to decide what belongs in Education and Experience, then use the resume bullet point examples to write those entries.
