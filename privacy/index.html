Privacy: Photos, Resume Text & Optional Analytics

Updated October 8, 2026 · JobFace product guide

In brief: JobFace’s photo and resume tools run in your browser. The application does not upload the image you choose or the resume text you enter to a processing service.

Photos and resume details

Selected photos are read into browser memory, cropped using a canvas and exported to your device. Resume text is placed into an HTML file generated locally. There is no JobFace account, cloud library or automatic backup. Closing or refreshing the page can discard your work; downloaded files remain wherever you save them.

We do not control browser extensions, device backups or other services you choose to upload your downloads to. Use a device you trust and avoid entering unnecessary sensitive information.

Website requests and hosting

Loading this site sends normal web requests to our hosting infrastructure, including Vercel. Those requests can include your IP address, browser information, requested address and time. “Processed in your browser” describes the tool inputs, not a claim that visiting a website creates no network traffic. See Vercel’s privacy policy.

Local preferences

The language selector stores your preferred language on this device. If optional analytics is configured, its consent choice is also stored locally. You can remove these preferences by clearing this site’s browser storage. We do not store resume form fields or photo content in local storage.

Optional usage analytics

Google Analytics is not loaded unless a verified measurement ID has been configured and you choose “Allow analytics.” If no analytics choice appears, analytics is not configured, or you have already made a choice. When configured, “Analytics choices” in the footer lets you allow or decline future tracking.

With permission, analytics measures page views, tool starts and clicks on valid photo or resume downloads. Tool events contain only a fixed tool category and photo format category. We do not send names, contact details, original file names, image content or resume text as event parameters. Page-view addresses omit query strings and fragments. Google’s analytics service may use cookies and process technical information such as IP addresses to derive approximate location; see Google’s privacy policy.

Declining or withdrawing consent stops future analytics calls from this implementation. It does not delete earlier records held by the provider. Downloads still work without analytics. A recorded download click is not proof that a user completed a job application.

Questions and safe reporting

Product behavior and privacy problems can be reported through the public project issue tracker. Do not include private photos, resumes or identifying details in a public report.
